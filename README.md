# TaskMate – Student Task Management System

## About
TaskMate is a responsive React application that helps students organize assignments, track deadlines, and monitor their progress.

## Features
- Landing page and dashboard
- Add new tasks with subjects, due dates, and descriptions
- View task details
- Mark tasks as pending or completed
- Delete tasks
- Responsive layout for desktop and mobile

## Technology Stack
- React.js
- JavaScript
- CSS
- Vite

## Run Locally
1. Install Node.js.
2. Open the project folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.

## Project Status
Frontend developed with sample task data. Tasks are currently stored in application state and are not connected to a backend database.
